# Photography Portfolio Web Application Proposal

## Project Overview
A complete full-stack photography portfolio platform with public website and secure admin dashboard.

---

## Delivered Modules

### 1) Public Website
- Home page with dynamic hero image
- About section with dynamic profile image and editable profile details
- Services page with category-wise service listing
- Gallery page with category filtering and load-more layout
- Separate Videos section with category filtering
- Contact page with inquiry form (name, email, message)
- Dynamic footer details (location, email, phone, Instagram)
- Fully responsive design (desktop + mobile)

### 2) Admin Dashboard
- Secure admin login
- Admin user creation with OTP verification
- Forgot password and reset password flow
- Protected admin routes
- Upload images and videos
- Edit media title/category
- Delete media with confirmation
- Replace Home hero image from dashboard
- Replace About profile image from dashboard
- Edit About content fields
- Edit/Delete Contact details
- Manage custom categories (add/edit/delete)
- Media and category stats display

### 3) Backend & Security
- Spring Boot REST APIs
- JWT-based authentication
- Password encryption/hashing
- Protected admin APIs
- Public content/gallery APIs
- Contact query email submission
- OTP audit endpoint for admin operations
- OpenAPI/Swagger API documentation
- CORS + stateless security configuration

---

## Technology Stack
- Frontend: React + TypeScript + Vite
- Backend: Spring Boot (Java)
- Authentication: JWT
- API Docs: Swagger/OpenAPI
